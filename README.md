# Yormayn Sierra Inmobiliaria

Primera versión de la página web estática para publicar con GitHub Pages.

## Archivos
- `index.html` — estructura de la web.
- `styles.css` — diseño y versión móvil.
- `script.js` — buscador básico de propiedades.
- `assets/logo.jpg` — logo entregado por el propietario.

## Antes de publicar
En `index.html` reemplazar:
- `57XXXXXXXXXX` por el número real de WhatsApp, incluyendo código de país.
- `correo@tudominio.com` por el correo real.
- Las propiedades de ejemplo por las propiedades reales.

## Publicación
Esta web no necesita servidor ni base de datos para esta primera versión. Puede publicarse gratis con GitHub Pages.
